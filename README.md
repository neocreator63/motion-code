# MOTION CODE

Сайт методички по моушн-роликам для Reels с помощью ИИ.

**Адрес:** https://neocreator63.github.io/motion-code/

## Как поменять цену, карту или Instagram
Открой `index.html` → в самом низу блок `НАСТРОЙКИ` → поменяй значения в кавычках → Commit changes. Сайт обновится через 1–2 минуты.
