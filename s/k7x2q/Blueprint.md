# Стиль «ЧЕРТЁЖ»

> Дизайн-система MOTION CODE для вертикального ролика 9:16. Загрузи файл в репозиторий и напиши в промте: «стиль — строго по файлу Blueprint.md».

**Скорость:** генерация — средне, рендер — быстро.
**Подходит для:** как устроено, наука, техника, бизнес-схемы, «разбор механизма».

## Как выглядит
Инженерный чертёж. Синий фон с тонкой белой сеткой, всё рисуется белыми линиями на глазах: схемы, размеры, стрелки-выноски, разрезы. Объясняет, как что-то устроено, шаг за шагом.

## Техника
- 1080×1920, 30 fps, Remotion (DOM/SVG; 3D не нужен).
- В каждой сцене 2–3 анимированных элемента, что-то меняется каждые 2–3 секунды.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| blue | `#0F3B78` | фон |
| grid | `rgba(255,255,255,.12)` | сетка |
| line | `#EAF2FF` | линии и текст |
| amber | `#FFB547` | акцент: главная деталь, ответ |

## Шрифты
IBM Plex Mono / любой моноширинный с кириллицей — подписи и размеры; Manrope 700 — заголовки.

## Приёмы
- линии чертятся по контуру, как будто карандашом
- выноски с подписями («А — двигатель») выезжают к деталям
- разрез: объект раскрывается, внутри — механизм
- размерные стрелки с цифрами
- номер листа и штамп в углу, как на настоящем чертеже

## Переходы
камера уезжает по листу к следующей схеме; лист перелистывается; деталь увеличивается до нового чертежа. Сцены перекрываются на 12–20 кадров, без чёрных промежутков.

## Звук
скрип карандаша, щелчки, тихий механический фон. Всё тише голоса.

## Ритм ролика
1. **0–2 с, хук:** главная фраза крупно + самый яркий приём стиля.
2. **Середина:** одна мысль — одна сцена, 5–10 секунд.
3. **Кульминация:** акцентный цвет занимает больше кадра.
4. **Финал:** короткий вывод и призыв подписаться.
