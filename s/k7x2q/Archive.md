# Стиль «АРХИВ»

> Дизайн-система MOTION CODE для вертикального ролика 9:16. Загрузи файл в репозиторий и напиши в промте: «стиль — строго по файлу Archive.md».

**Скорость:** генерация — средне, рендер — быстро.
**Подходит для:** история, биографии, «как это было», великие люди, события.

## Как выглядит
Документальный фильм. Приглушённые тёплые тона, плёночное зерно и виньетка. Камера медленно наезжает и панорамирует по фото, картам и документам (эффект Кена Бёрнса). Старые карты с прорисовкой маршрутов, печати, рукописи, газетные вырезки. Плашки «место · год» внизу экрана.

## Техника
- 1080×1920, 30 fps, Remotion (DOM/SVG; 3D не нужен).
- В каждой сцене 2–3 анимированных элемента, что-то меняется каждые 2–3 секунды.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| paper | `#E7DCC6` | бумага |
| sepia | `#8A6A45` | тени, линии |
| ink | `#231A12` | текст |
| red | `#B23A2A` | маршруты, пометки |
| film | `#0E0B08` | затемнения |

## Шрифты
Playfair Display (заголовки, курсив для цитат) + Courier Prime / любой моноширинный с кириллицей для дат и плашек «место · год».

## Приёмы
- эффект Кена Бёрнса на каждой картинке: медленный зум 100→112% и сдвиг
- карта: красная линия маршрута прорисовывается, точки городов вспыхивают
- печать «ДОКУМЕНТ / 1964» ударом падает на лист
- газетная вырезка выезжает с тенью
- для своих фото: загрузи их в репозиторий — Claude сделает из них архивные кадры

## Переходы
мягкое растворение; затемнение до тёмно-коричневого; перелистывание страницы. Сцены перекрываются на 12–20 кадров, без чёрных промежутков.

## Звук
шорох плёнки, щелчок проектора, перелистывание; без музыки. Всё тише голоса.

## Ритм ролика
1. **0–2 с, хук:** главная фраза крупно + самый яркий приём стиля.
2. **Середина:** одна мысль — одна сцена, 5–10 секунд.
3. **Кульминация:** акцентный цвет занимает больше кадра.
4. **Финал:** короткий вывод и призыв подписаться.
