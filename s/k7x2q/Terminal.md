# Стиль «ТЕРМИНАЛ»

> Дизайн-система MOTION CODE для вертикального ролика 9:16. Загрузи файл в репозиторий и напиши в промте: «стиль — строго по файлу Terminal.md».

**Скорость:** генерация — быстро, рендер — быстро.
**Подходит для:** технологии, ИИ, кибербезопасность, «взлом мозга», тайны, факты.

## Как выглядит
Экран хакерского терминала. Чёрный фон, зелёный моноширинный текст, курсор, строки кода, всплывающие окна, сканирующие полосы и глитч. Ощущение, что зритель смотрит в секретные данные.

## Техника
- 1080×1920, 30 fps, Remotion (DOM/SVG; 3D не нужен).
- В каждой сцене 2–3 анимированных элемента, что-то меняется каждые 2–3 секунды.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| black | `#030806` | фон |
| green | `#3BFF8A` | текст |
| dim | `#1E6B43` | второстепенное |
| alert | `#FF4D4D` | тревога, ошибка |

## Шрифты
JetBrains Mono / Fira Code с кириллицей — всё; заголовки — тот же шрифт, крупно.

## Приёмы
- текст печатается посимвольно с курсором
- окна-всплывашки «ACCESS GRANTED», «ERROR 404»
- горизонтальные полосы скана и шум ЭЛТ-экрана
- прогресс-бар загрузки из символов [██████░░░]
- матрица символов на фоне на акцентах

## Переходы
глитч-разрыв кадра на 3–4 кадра; новое окно открывается поверх; экран «перезагружается». Сцены перекрываются на 12–20 кадров, без чёрных промежутков.

## Звук
клавиатура, писки терминала, цифровой шум. Всё тише голоса.

## Ритм ролика
1. **0–2 с, хук:** главная фраза крупно + самый яркий приём стиля.
2. **Середина:** одна мысль — одна сцена, 5–10 секунд.
3. **Кульминация:** акцентный цвет занимает больше кадра.
4. **Финал:** короткий вывод и призыв подписаться.

## Строка стиля для промта
