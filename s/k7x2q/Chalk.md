# Стиль «МЕЛ»

> Дизайн-система MOTION CODE для вертикального ролика 9:16. Загрузи файл в репозиторий и напиши в промте: «стиль — строго по файлу Chalk.md».

**Скорость:** генерация — быстро, рендер — быстро.
**Подходит для:** обучение, объяснения «как ребёнку», формулы, планы, лайфхаки.

## Как выглядит
Школьная доска. Тёмно-зелёный фон с разводами, всё рисуется мелом на глазах: схемы, стрелки, человечки, формулы. Как будто учитель объясняет сложное простыми рисунками.

## Техника
- 1080×1920, 30 fps, Remotion (DOM/SVG; 3D не нужен).
- В каждой сцене 2–3 анимированных элемента, что-то меняется каждые 2–3 секунды.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| board | `#1F3A2E` | доска |
| smudge | `rgba(255,255,255,.06)` | разводы |
| chalk | `#F2F2EC` | мел |
| yellow | `#F7E26B` | цветной мел — главное |
| pink | `#F59BB0` | цветной мел — ошибка |

## Шрифты
Caveat 700 (рукописный, с кириллицей) — весь текст; цифры крупно.

## Приёмы
- линии рисуются по контуру с неровным «меловым» штрихом
- человечки-палочки показывают действия
- главное обводится жёлтым мелом в кружок
- ошибка перечёркивается розовым
- тряпка стирает часть доски — и там новый рисунок

## Переходы
тряпка стирает доску; камера сдвигается вдоль длинной доски; рисунок «сдувается» меловой пылью. Сцены перекрываются на 12–20 кадров, без чёрных промежутков.

## Звук
скрип мела, стук, шорох тряпки. Всё тише голоса.

## Ритм ролика
1. **0–2 с, хук:** главная фраза крупно + самый яркий приём стиля.
2. **Середина:** одна мысль — одна сцена, 5–10 секунд.
3. **Кульминация:** акцентный цвет занимает больше кадра.
4. **Финал:** короткий вывод и призыв подписаться.
