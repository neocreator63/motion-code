# Стиль «НЕОН»

> Дизайн-система MOTION CODE для вертикального ролика 9:16. Загрузи файл в репозиторий и напиши в промте: «стиль — строго по файлу Neon.md».

**Скорость:** генерация — средне, рендер — средне.
**Подходит для:** факты, психология, «а ты знал», технологии, город, ночь.

## Как выглядит
Ночной город тёмно-синего цвета с размытыми огнями (боке). Все объекты — светящийся неоновый лайн-арт без заливки, с отражением на мокром глянцевом полу. Объекты соединены пунктиром и плавно перетекают друг в друга (велосипед → машина → вертолёт). Текст печатается как на машинке, с курсором и лёгким глитчем.

## Техника
- 1080×1920, 30 fps, Remotion (DOM/SVG; 3D не нужен).
- В каждой сцене 2–3 анимированных элемента, что-то меняется каждые 2–3 секунды.

## Палитра
| Токен | Цвет | Где |
|---|---|---|
| night | `#070B1A` | фон |
| haze | `#16203F` | дома, дымка |
| cyan | `#2EE6D6` | основной неон |
| magenta | `#FF3D7F` | акцент: «ловушка», ошибка, стоп |
| ink | `#E8F6FF` | текст |

## Шрифты
JetBrains Mono 700 (или любой моноширинный с кириллицей) — заголовки капсом, межбуквенный 0.25em; ключевое слово — бирюзой.

## Приёмы
- лайн-арт рисуется по контуру (stroke-dashoffset), потом вспыхивает свечением
- пунктирная линия-связь бежит от объекта к объекту
- отражение в полу — копия с прозрачностью 25% и размытием
- сверху сегментированный прогресс-бар по сценам, как в сторис
- окна домов мигают в ритме слов

## Переходы
морф одного контура в другой; вспышка неона; пролёт камеры вдоль пунктира. Сцены перекрываются на 12–20 кадров, без чёрных промежутков.

## Звук
тихий синт-гул, щелчки печати, электрический треск на глитче. Всё тише голоса.

## Ритм ролика
1. **0–2 с, хук:** главная фраза крупно + самый яркий приём стиля.
2. **Середина:** одна мысль — одна сцена, 5–10 секунд.
3. **Кульминация:** акцентный цвет занимает больше кадра.
4. **Финал:** короткий вывод и призыв подписаться.
