Промт Первого Запуска

Подготовь этот репозиторий для моушн-роликов на Remotion.
1. Установи официальные скиллы Remotion из github.com/remotion-dev/skills в .claude/skills (например: npx skills add remotion-dev/skills). Проверь, что есть remotion-best-practices.
2. Проверь ffmpeg, Node, Python и faster-whisper. Чего нет — установи.
3. Создай в корне CLAUDE.md с правилами:
- Каждый ролик — отдельная папка rolikN в корне, свой проект Remotion. Перед работой используй скилл remotion-best-practices.
- Формат 1080×1920, 30 fps, длительность = длина озвучки.
- Если дан готовый файл озвучки — новую не делай: перенеси его в папку ролика как public/voice.mp3, нормализуй до -14 LUFS, распознай faster-whisper с таймкодами слов и привязывай сцены и анимации к словам. Если файла нет, но есть GEMINI_API_KEY — озвучь через Gemini TTS, иначе спроси меня.
- В каждой сцене 2–3 анимированных элемента по смыслу. Нет кадров «только текст» дольше 1,5 с. Что-то меняется каждые 2–3 с. Сильный хук в первые 2 с.
- Текст — только внутри сцен, по словам. Отдельную дорожку субтитров не делай, если я не попрошу.
- Переходы только плавные (растворение, наплыв, перетекание объекта), сцены перекрываются на 12–20 кадров. Без резких сдвигов и чёрных промежутков.
- Голос главный, эффекты тише голоса. Фон — только тихий эмбиент, если стиль не говорит иначе.
- Шрифты только с поддержкой кириллицы.
- Порядок: контакт-лист (кадр каждые 3 с) в rolikN/preview.jpg и кадры стыков в rolikN/transitions.jpg → пришли ссылки → продолжай рендер, если я не написал «жди».
- Итог: rolikN/out/rolikN.mp4 до 90 МБ (больше — снизь битрейт и перерендерь). Временные файлы не коммить.
- В конце: коммит, пуш, pull request в main и две ссылки — на PR и прямую на MP4 вида github.com/ВЛАДЕЛЕЦ/reels/raw/main/rolikN/out/rolikN.mp4.
- Ключи только из переменных окружения, никогда не записывай их в файлы.
4. Закоммить, запушь, открой pull request в main и пришли ссылку.
